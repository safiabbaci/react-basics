## Project Details

### 01 · `project-01`
Getting started with React — project setup, the basic file structure, and rendering a first component to the DOM.

### 02 · `project-02`
Continuing React fundamentals — JSX syntax, nesting elements, and how components fit together.

### 03 · `project-03_Cards`
Building reusable card components — passing data through props to render repeated UI like product or profile cards.

### 04 · `project-04_CSS`
Styling components with plain CSS — importing stylesheets, className usage, and basic layout.

### 05 · `project-05_Tailwind`
Styling with Tailwind CSS — utility-first classes for layout, spacing, color, and responsive design.

### 06 · `project-06_UI`
Assembling small UI components — combining layout and styling concepts into reusable interface pieces.

### 07 · `project-07_Functions`
Functions and props in depth — passing data and callback functions between parent and child components.

### 08 · `project-08_UseState`
Introduction to the `useState` hook — managing simple local component state (counters, toggles, inputs).

### 09 · `project-09_UseStateAdvance`
Advanced `useState` patterns — managing objects and arrays in state, and updating state based on previous values.

### 10 · `project-10_FormHandling`
Handling forms in React — controlled inputs, form submission, and basic validation.

### 11 · `project-11_NotesApplication`
A notes-taking application — a mini project combining state, forms, and lists to add, display, and remove notes.

### 12 · `project-12_LocalStorage`
Persisting data with the browser's `localStorage` API — saving and restoring state across page reloads.

### 13 · `project-13_APICalling`
Fetching data from external APIs — using `fetch`/`async-await` to load and display remote data.

### 14 · `project-14_UseEffect`
Introduction to the `useEffect` hook — side effects, dependency arrays, and syncing components with external data.

### 15 · `project-15_GalleryApplication`
An image gallery application — a mini project rendering a collection of images, likely combined with filtering or API data.

### 16 · `project-16_ReactRouterDom`
Routing with `react-router-dom` — setting up routes, links, and navigating between pages in a single-page app.

### 17 · `project-17_AdvanceRouting`
Advanced routing patterns — nested routes, dynamic route parameters, and protected/conditional routes.

### 18 · `project-18_ContextAPI`
State management with the Context API — sharing state across components without prop drilling.

## Getting Started

Each project is a standalone React app. To run one:

```bash
cd project-XX_Name
npm install
npm start
```

(Some projects may use `npm run dev` instead, depending on whether they were created with Create React App or Vite — check the `package.json` inside the folder.)

## Prerequisites

- [Node.js](https://nodejs.org/) (v16 or later recommended)
- npm (comes bundled with Node.js)

## Purpose

This repository serves as a personal learning log for React — each folder captures a step forward, from basic components to a full notes/gallery app with routing and context-based state management.
